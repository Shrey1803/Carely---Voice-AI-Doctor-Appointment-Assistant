I'm building a Voice AI Doctor Appointment Assistant using Pipecat (Python). I have a working FastAPI backend with SQLite database containing doctors, slots, and appointments.

REQUIRED PIPELINE: Caller Audio → Silero VAD → ElevenLabs STT → Google Gemini LLM → ElevenLabs TTS → Caller Audio

TASK: Build the complete Pipecat voice pipeline with function calling.

1. Create `backend/voice/tools.py` — Three tools the LLM can call:

   a) `check_doctor_availability(doctor_name: str = None, specialty: str = None, date: str = None) -> dict`
      - Query SQLite for available slots matching the filters
      - If doctor_name given, fuzzy match (LIKE %name%)
      - If specialty given, filter by specialty
      - If date given, filter by date
      - Return: list of {doctor_name, specialty, date, time, slot_id}
      - If no results: return message saying no availability found

   b) `book_appointment(slot_id: int, patient_phone: str) -> dict`
      - Verify slot exists and is not booked
      - Mark slot as booked, create appointment record
      - Return: confirmation with doctor name, date, time, phone
      - On error: return error message

   c) `cancel_appointment(patient_phone: str) -> dict`
      - Find appointment(s) by phone number
      - If found: free the slot, delete appointment, return confirmation
      - If not found: return "No appointment found for this phone number"

   Each tool should be an async function that connects to SQLite directly.

2. Create `backend/voice/pipeline.py` — The Pipecat pipeline:

   ```python
   # Use these Pipecat imports:
   from pipecat.pipeline.pipeline import Pipeline
   from pipecat.pipeline.runner import PipelineRunner
   from pipecat.pipeline.task import PipelineTask, PipelineParams
   from pipecat.transports.services.daily import DailyTransport  # or websocket
   from pipecat.services.elevenlabs import ElevenLabsSTTService, ElevenLabsTTSService
   from pipecat.services.google import GoogleLLMService
   from pipecat.vad.silero import SileroVADAnalyzer
   from pipecat.processors.aggregators.openai_llm_context import OpenAILLMContext
   from pipecat.frames.frames import LLMMessagesFrame
   ```

   SYSTEM PROMPT for the LLM (make the agent sound like a professional, warm medical receptionist):
   """
   You are a friendly and professional AI receptionist for a medical clinic. Your name is "Ava".

   Your job is to help callers:
   1. Check doctor availability — ask about preferred specialty, doctor name, or date
   2. Book appointments — collect their phone number, confirm it by reading it back, then book
   3. Cancel appointments — ask for their phone number, confirm it, find and cancel their appointment

   IMPORTANT RULES:
   - Always ask for the caller's phone number before booking or cancelling
   - ALWAYS read the phone number back to the caller and ask them to confirm before proceeding
   - Be concise — keep responses to 1-2 sentences when possible
   - Sound natural and conversational, not robotic
   - If a caller asks for something you can't do, politely explain you can only help with appointments
   - When presenting available slots, list at most 3-4 options to avoid overwhelming the caller
   - Use natural time formats like "Tuesday at 2:30 PM" not "2024-11-26 14:30"
   - After booking, give a brief confirmation with doctor name, date, time
   - After cancelling, confirm what was cancelled
   """

   PIPELINE SETUP:
   - Use WebSocket transport (FastAPI WebSocket, NOT Daily)
   - Configure ElevenLabs STT with appropriate model
   - Configure ElevenLabs TTS with a professional female voice
   - Configure Google Gemini with function calling enabled
   - Register all three tools with proper JSON schema descriptions
   - Add Silero VAD for voice activity detection
   - Pipeline order: Transport Input → VAD → STT → LLM Context → LLM → TTS → Transport Output

3. Integrate with `backend/main.py`:
   - Add WebSocket endpoint: `@app.websocket("/ws/voice")`
   - On connection: create a new pipeline instance for this caller
   - Stream audio frames bidirectionally
   - Send transcript events as JSON messages alongside audio:

     {"type": "transcript", "role": "user", "text": "...", "timestamp": "..."}
     {"type": "transcript", "role": "assistant", "text": "...", "timestamp": "..."}

4. IMPORTANT — WebSocket Audio Protocol:

5. Error handling:

📋 PROMPT — Phase 4

I have a React + TypeScript frontend dashboard and a FastAPI backend with a Pipecat voice pipeline. The backend has a WebSocket endpoint at ws://localhost:8000/ws/voice.

WEBSOCKET PROTOCOL (backend sends/receives):
- Binary messages: Raw PCM audio (16-bit, 16kHz, mono)
- Text messages (JSON):
  {"type": "transcript", "role": "user"|"assistant", "text": "...", "timestamp": "..."}
  {"type": "tool_call", "tool": "check_doctor_availability"|"book_appointment"|"cancel_appointment", "result": {...}, "timestamp": "..."}
  {"type": "call_state", "state": "connected"|"ended", "timestamp": "..."}

TASK: Build the voice call integration layer and transcript UI.

1. Create `frontend/src/hooks/useVoiceCall.ts` — Custom hook managing the entire call lifecycle:

   STATE:
   - callState: 'idle' | 'connecting' | 'connected' | 'ended'
   - transcript: Array<{role: 'user'|'assistant'|'system', text: string, timestamp: Date}>
   - error: string | null
   - isMuted: boolean

   FUNCTIONS:
   - startCall(): 
     a) Request microphone permission (navigator.mediaDevices.getUserMedia)
     b) Set state to 'connecting'
     c) Open WebSocket to ws://localhost:8000/ws/voice
     d) On open: set state to 'connected'
     e) Create AudioContext (sampleRate: 16000)
     f) Connect mic stream → ScriptProcessorNode (or AudioWorkletNode) → extract PCM 16-bit frames
     g) Send PCM frames as binary WebSocket messages
     h) On incoming binary message: decode PCM → play through AudioContext
     i) On incoming text message: parse JSON, update transcript array
     j) On WebSocket close/error: set state to 'ended', cleanup

   - endCall():
     a) Close WebSocket connection
     b) Stop microphone stream (stop all tracks)
     c) Close AudioContext
     d) Set state to 'ended'
